# Testliste DriveLog

## Basis

- App startet ohne Fehler.
- Dashboard wird angezeigt.
- Dunkles Design wird korrekt geladen.

## Fahrzeuge

- Fahrzeug mit Marke, Modell, Kennzeichen und VIN speichern.
- Fahrzeug bearbeiten.
- Fahrzeug löschen.
- Fahrzeugschein-Daten anzeigen.
- TÜV-Datum eintragen.
- TÜV-Hinweis prüfen, wenn Datum abgelaufen ist.

## Fahrten

- Fahrt manuell eintragen.
- Kilometer automatisch berechnen lassen.
- Fahrt bearbeiten.
- Fahrt löschen.
- Fahrtenliste filtern und durchsuchen.
- CSV in Zwischenablage kopieren.

## GPS

- GPS-Fahrt öffnen.
- Fahrzeug auswählen.
- Hinweisdialog erscheint vor Start.
- Start nur nach Bestätigung möglich.
- GPS-Berechtigung wird angefragt.
- Fahrt beenden und speichern.
- Durchschnittsgeschwindigkeit wird berechnet.
- Höchstgeschwindigkeit wird gespeichert.

## Tankbelege

- Tankbeleg manuell speichern.
- Foto-Button öffnet Kamera oder Galerie.
- OCR-Vorschläge werden übernommen, wenn Android/iOS verwendet wird.
- Auf Windows bleibt die App stabil und erklärt den Fallback.
- Preis pro Liter wird berechnet.

## Probleme

- Problem für Fahrzeug melden.
- Bauteil, Beschreibung, Dringlichkeit und Kilometerstand speichern.
- Status auf in Prüfung setzen.
- Status auf erledigt setzen.
- Problem löschen.

## Statistik

- Gesamtkilometer stimmen.
- Kilometer je Fahrzeug stimmen.
- Durchschnittsgeschwindigkeit wird angezeigt, wenn GPS-Daten vorhanden sind.
- Durchschnittsverbrauch wird angezeigt, wenn Liter eingetragen wurden.


## Update: Autocomplete und Vorschläge

Die App wurde um professionelle Vorschlagsfelder erweitert. Beim Eingeben von Orten erscheinen passende Vorschläge, zum Beispiel Leutkirch, Lindau, Ravensburg oder Bad Saulgau. Zusätzlich kann DriveLog mit Internet echte Ortsvorschläge über OpenStreetMap/Nominatim laden. Fahrzeuge können über Marke, Modell, Kennzeichen oder VIN gesucht werden. Weitere Vorschläge gibt es bei Fahrzeugdaten, Tankstellen und Problemberichten.

Diese Erweiterung verbessert die Bedienung, bleibt aber verständlich, weil sie über eigene kleine Services und Widgets umgesetzt wurde.
